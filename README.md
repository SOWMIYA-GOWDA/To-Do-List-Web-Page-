**1. Introduction**

This project is a basic To-Do List Web App developed to help users organize and manage daily activities effectively.
It is created using HTML, CSS, and JavaScript, offering an interactive task manager that lets users add, finish, and remove tasks.
The application is designed with a simple, responsive, and user-friendly interface.

**2. Objectives**

Create a responsive and engaging task management web page

Enable users to add new tasks, mark them as done, and delete them

Provide a neat and minimal interface with smooth usability

Showcase the application of core frontend technologies (HTML, CSS, JavaScript)

**3. Methodology**

**Frontend:** HTML for layout, CSS for appearance, JavaScript for interactivity

**Design:** Card-based layout with a modern look and styled buttons

**Process:**

Input field and button for entering tasks

Dynamic display of task list

Checkbox to mark tasks as completed

Delete option to remove tasks

**4. Features**

📝 **Add Tasks:** Quickly input and add new tasks
✅ **Mark as Done:** Use checkboxes to strike through completed tasks
❌ **Delete Tasks:** Instantly remove unwanted tasks
🎨 **UI/UX:** Simple design with hover effects and smooth transitions
⌨️ **Keyboard Support:** Add tasks by pressing the Enter key

**5. Conclusion**

The To-Do List Web App illustrates how frontend technologies can be combined to build an interactive and useful task management tool.
It delivers a lightweight yet efficient platform for organizing tasks while demonstrating JavaScript concepts like DOM manipulation, event handling, and UI design.
